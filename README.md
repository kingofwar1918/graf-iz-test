# Lernjournal Graf-iz: Rhesi am Alpenrhein

Lernapp für die 2. Oberstufe (Sek): Graf-iz 1 bis 4 zur Einheit «Wie viel Platz soll der Rhein bekommen?».

- Läuft im Browser, ohne Login. Eingaben bleiben nur auf dem Gerät (localStorage), nichts wird übertragen.
- Am Schluss erstellt die App ein Word (.docx), das die Lernenden per Mail oder Teams abgeben.
- Sicherung als Datei speichern und wieder laden.

Die Texte stehen oben in `index.html` im Block `DATEN`.
